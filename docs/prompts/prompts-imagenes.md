# ConsultaRUC.pe — Image Prompt Pack (Nano Banana Pro)

Cómo usar este archivo:

1. Copia el **MASTER DESIGN PROMPT** una vez.
2. Para cada imagen, pega el master + el **IMAGE PROMPT** de esa sección en Nano Banana Pro.
3. Usa el **ALT TEXT** en el atributo `alt=""` del `<img>` en el artículo.

Todas las imágenes deben verse como una **serie coherente** (mismo estilo, misma paleta, misma marca).
